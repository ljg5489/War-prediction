[README] GDELT 일일 집계(Daily Aggregation) 데이터셋 명세서

# 파일명: GDELT_Daily_30_Countries.csv
# 데이터 출처: GDELT Project (FIPS 10-4 기준 30개국)
# 추출 방식: BigQuery SQL을 통한 15분 단위 데이터의 일별 요약 (AVG/SUM)
# 데이터 기간: 2013년 1월 1일 ~ 2026년 현재
# 데이터 성격: 특정 날짜/국가/사건(CAMEO)별 언론 반응 및 파급력 요약

-----------------------------------------------------------------------------
[1. 변수 정의 및 집계 방식 (Variable Definitions)]
-----------------------------------------------------------------------------
* 모든 데이터는 [날짜 / 국가 / 사건코드]를 기준으로 GROUP BY 되었습니다.

1. SQLDATE
   - 설명: 사건 발생 날짜 (YYYYMMDD 형식)
   - 역할: 시계열 분석의 기준 인덱스 (Daily Time-step)

2. ActionGeo_CountryCode
   - 설명: 사건이 발생한 국가의 FIPS 10-4 코드 (2자리 알파벳)
   - 참고: ACLED/V-Dem과 병합 시 ISO-3 코드로의 변환이 필요할 수 있음

3. EventCode
   - 설명: CAMEO 사건 분류 코드
   - 역할: 사건의 종류(협력, 시위, 공격 등) 식별

4. AvgGoldstein (일일 평균 골드스타인 지수)
   - 집계: AVG(GoldsteinScale)
   - 설명: 해당 날짜/국가/사건이 안정성에 미치는 이론적 영향력의 평균치 (-10 ~ +10)

5. AvgTone (일일 평균 어조)
   - 집계: AVG(AvgTone)
   - 설명: 해당 날짜/국가/사건을 다룬 기사들의 평균적인 감조(Sentiment). 낮을수록 부정적.

6. TotalMentions (일일 총 언급 횟수)
   - 집계: SUM(NumMentions)
   - 설명: 해당 날짜에 해당 사건이 뉴스에서 언급된 총 횟수 (화제성 지표)

7. TotalSources (일일 총 정보원 수)
   - 집계: SUM(NumSources)
   - 설명: 해당 사건을 보도한 고유 뉴스 매체(출처)의 총합 (확산성 지표)

8. TotalArticles (일일 총 기사 수)
   - 집계: SUM(NumArticles)
   - 설명: 해당 사건과 관련해 발행된 개별 기사의 총합 (보도 집중도 지표)

-----------------------------------------------------------------------------
[2. 대상 국가 그룹 분류 (30개국)]
-----------------------------------------------------------------------------
[Group A: 활성 분쟁 (10개국)]
- SY, YM, SO, BM, ET, OD, ML, CG, UP, IZ

[Group B: 고위험 잠재 (10개국)]
- PK, NI, VE, SU, CT, TW, HA, LE, CO, EC

[Group C: 안정 대조군 (10개국)]
- NO, SZ, JA, KS, PO, UY, BC, MG, CA, GM

-----------------------------------------------------------------------------
[3. 데이터 특징 (Data Characteristics)]
-----------------------------------------------------------------------------
- 본 데이터셋은 BigQuery의 연산 능력을 이용해 약 94GB의 원본 데이터를 
  핵심 지표 위주로 압축한 결과물임.
- 15분 단위의 노이즈를 제거하고 '일별 추세'에 집중하도록 설계되어 있어, 
  LSTM 등 딥러닝 모델의 학습 효율이 극대화됨.
