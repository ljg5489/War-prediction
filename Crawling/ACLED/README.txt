# 데이터 형태: 일별(Daily) 이벤트 단위 시계열 데이터

-----------------------------------------------------------------------------
[1. 변수 정의서 (Data Dictionary)]
-----------------------------------------------------------------------------
1. event_id_cnty
   - 설명: 사건 고유 ID (예: SYR12345)
   - 용도: 중복 데이터 제거(Drop Duplicates) 및 개별 사건 식별

2. event_date
   - 설명: 사건 발생 날짜 (YYYY-MM-DD 형식)
   - 용도: 시계열 예측(LSTM 등) 모델링의 기준점(Time Index) 및 GDELT 데이터와의 병합 Key

3. year
   - 설명: 사건 발생 연도
   - 용도: 연도별 V-Dem 데이터와의 병합(Merge) Key

4. event_type
   - 설명: 사건 대분류 (예: Battles, Protests, Riots, Explosions)
   - 용도: 분쟁의 거시적 형태 파악 및 범주형 변수(One-hot Encoding) 활용

5. sub_event_type
   - 설명: 사건 소분류 (예: Armed clash, Peaceful protest)
   - 용도: 평화 시위가 무력 충돌로 에스컬레이션되는 세부 패턴 학습

6. interaction
   - 설명: 행위자 상호작용 형태를 나타내는 2자리 숫자 코드 (예: 10=정부군 단독, 12=정부군 vs 반군)
   - 용도: 분쟁의 성격(내전, 테러, 민중 봉기 등)을 숫자 벡터로 변환하여 모델에 입력

7. fatalities
   - 설명: 해당 사건으로 인한 사망자 수
   - 용도: 분쟁의 '강도(Severity)' 및 '위험도(Risk)'를 산출하는 가장 핵심적인 연속형 타겟 변수

8. latitude
   - 설명: 위도 (사건 발생 지점)
9. longitude
   - 설명: 경도 (사건 발생 지점)
   - 용도(8, 9): 공간 분석 및 지역별 분쟁 스필오버(Spillover, 인접 지역 전파) 효과 학습

10. country
    - 설명: 국가명
    - 용도: 데이터를 국가별로 그룹화(Groupby)하기 위한 식별자

[3. 전처리 시 주의사항 (Preprocessing Notes)]
-----------------------------------------------------------------------------
1. 보츠와나의 중간 이빨 빠진 연도(결측 연도)는 해당 시기에 물리적 이벤트(시위/충돌)가 0건이었거나 기록되지 않은 것이므로, 모델링 시 '이벤트 0건' 또는 '보간법(Interpolation)'으로 처리할 것.
2. event_date 변수의 오타(event_data)는 파이썬에서 즉시 date 타입으로 형변환하여 사용할 것.
