# War-prediction
인공지능 개론 과제 (전쟁예측 AI 모델 구축)
[발표일: 14주 차

팀 구성: 팀당 4-5명씩 구성 (총 6팀)

발표 시간: 20분 ~ 25분 발표 (조장은 +3점)

발표 내용: 캐글, 통계청 등에서 데이터를 자유롭게 선정하여 AI/ML 모델 구축 및 발표

예시:

비즈니스 문제 정의 및 분석 / 모델 목표 설정

탐색적 데이터 분석(EDA) 및 시각화 분석

데이터 전처리 및 파생변수 생성

AI/ML 모델 구축 과정 설명 (모델 설정, 모델 비교 및 성능 평가)

-크롤링(정하경, 정재헌, 이성민)
-데이터 분석 및 시각화 분석(정하경, 정재헌, 이성민)
-데이터 전처리(이진규, 유준석)
-AI/ML 모델 구축 과정 설명(모델 설정, 모델 비교 및 성능 평가(이진규, 유준석)

주제:  전쟁 위험도를 판단하여 당일부터 3개월 후 사이에 전쟁이 일어날 확률을 계산하는 AI 모델
